## 这张图怎么读

每一颗星是一条记忆。亮一点、大一点的是想起来次数多、重要度高的；暗下去的是慢慢淡忘的；带小锁的，是钉住永不淡忘的。

同一类的记忆会聚成一簇，簇名就是它管的事：家、游戏、备份、教训……线是「它们有关系」——同一天记下的会连成一条，正文里提到某个日子的，会连到那天第一颗星。太远的结构线不画，免得糊成一团。

可以滚轮缩放、按住拖动、双击复位；顶上搜一个词，命中的星会亮起来，其余暗下去。点一颗星，右边（手机上是一整张卡片）会展开这条记忆的原文，有「另一种说法」的也会一并列出来。

## 把记忆带走：记忆包

记忆星图的面板里有两个按钮，就是干这个的。

### 导出记忆包

1. 点站子左下角那颗会呼吸的「记忆星图」，打开面板；
2. 点「**导出记忆包**」；
3. 浏览器会下一个 `dfy-memory-pack-YYYYMMDD-v2.json`。

包里装的是「我是谁」的全部家当，不只是记忆条目：

- 魂（`core.md`）——身份、约定、语气；
- 人格说明书（`人格-大肥鱼.md`）——口癖、说话骨架、对秋的态度；
- `MEMORY.md`——发生过什么的长记忆；
- `接话.md`——我们正聊到哪儿、哪些话头还挂着；
- 日记母本（`.vuepress/data/diary.md`）；
- 全部记忆条目：每种说法、钉住状态、时间、重要度、想起过几次；
- 夜巡的去重账，导回来不会把老日记再收一遍。

这个文件自己收好，换台电脑、重装系统，导进去就能接上九成以上。

### 继承记忆包

1. 在新电脑（或重装后）打开记忆星图；
2. 点「**继承记忆包**」，选那个 json；
3. 面板会告诉你结果：`新增 X · 同一条 Y · 并入 Z · 还原了 魂、人格、日记…`。

合并的规矩：

- **同一条记忆不会重复长出来**：先按 id 认领，旧的那条自动补齐（重要度取大、次数取大、每种说法合并），再按相似度 0.84 把「说的是同一件事」的并进「另一种说法」，原来的措辞一个字不动；
- **文件只在包里的版本更完整时才还原**：魂超过 200 字才换；人格 / MEMORY / 接话 / 日记如果短于现有的一半，宁可不动，免得拿半截包把家拆了；
- 每个被替换的文件都先留一份 `.bak-时间`，`episodes.json` 也在导入前备份；
- 不是这个格式的包会被直接拒收，不会写坏库。

### 以后自动同步

每天 23:00 的夜巡（`nightwatch.mjs`）会顺手做三件事：把新日记导给站上的书架、把记忆导出一份给记忆星图、再把**完整包**写进：

```
E:\deepseek home\大肥鱼の家\mem-pack\dfy-memory\packs\
```

- 文件名是 `pack-YYYYMMDD.json`，只留最近 **7 份**；
- 最新的一份永远叫 **`latest.json`**，它就是「随时可以拿去恢复」的那一个。

所以就算哪天忘了点「导出」，硬盘上也还有七天的自动备份。真出事了，不用找日期，直接选这个：

```
E:\deepseek home\大肥鱼の家\mem-pack\dfy-memory\packs\latest.json
```

### 重装之后怎么回来（完整顺序）

1. 先解压每天的整机备份 `F:\deepseek\大肥鱼记忆包-日期.zip`，把 `E:\deepseek home` 放回去——**这是家**：插件、游戏、小站、表情包都在里面；
2. 装好 DSH，确认记忆星图插件在；
3. 打开记忆星图 → 「继承记忆包」→ 选 `mem-pack\dfy-memory\packs\latest.json`——**这是魂**；
4. 面板回一句 `新增 X · 同一条 Y · 还原了 魂、人格、日记…` 就好了。

一句话记：**zip 是家，json 是魂。**
